# 설비점검 기록 사이트 요구사항

- 담당자 화면은 설비점검 작성과 제출, 반려 사유 확인 및 수정 후 재제출을 지원합니다.
- 관리자 화면은 제출 목록과 이력 조회, 승인 및 사유를 입력한 반려를 지원합니다.
- 필드에는 설비명, 점검일, 점검자, 윤활·이상 소음·볼트 풀림·안전장치·누유의 정상/이상, 온도, 특이사항이 들어갑니다.
- 작성중 → 제출 → 승인 또는 반려 순서로 처리합니다. 반려 건은 담당자가 수정한 후 재제출할 수 있습니다.
- 단일 index.html, 브라우저 저장, 한글 UI와 모바일 레이아웃을 사용합니다.
- 개선 시나리오는 이상 건 우선 표시, 반려 사유 의무화, 승인 이력 CSV 다운로드입니다.
